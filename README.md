# Once Upon a Time in Benedict Canyon

A Stardew-Valley-style farming/adventure game set in 1969 Hollywood, playable in any modern browser.
Open `index.html` — no build step, no dependencies. (Fan-made fictional parody; no real people appear.)

You are Cliff Booth, stuntman and handyman to washed-up TV cowboy Rick Dalton. You have 7 days to farm, charm, solve puzzles and get Rick one last shot at stardom.

**Controls:** WASD/Arrows move · Space use tool · E talk/interact · 1-4 tools · Q switch seed · J journal · M mute

**Features:** day/night + rain, farming (3 crops), detailed animated pixel-art dialogue portraits, branching dialogue with consequences (relationships, Rick's confidence, clues), 5 puzzles (script ordering, fuse-box wiring, Simon-style dog tricks, sliding poster, safe cracking), 4 endings, autosave on sleep.
